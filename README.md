# The Funniest Sick-Day Excuse

One line (≤200 characters): a funny reason to call in sick.

> My cat walked across my keyboard and submitted my resignation to a rival company, so I'm spending today in damage control.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
